## 🧪 About M!N L@B

M!N L@B is a software studio from Bangladesh. We believe premium-quality digital tools should not be a luxury: they should speak the language of ordinary people, keep working when the network doesn't, and protect their data like it matters. Because it does.

We build products for the people who actually run Bangladesh's economy: shopkeepers, dealers, distributors and small business owners, and we design them to work together as one ecosystem.

## 🎯 What we stand for

| | |
|---|---|
| 🇧🇩 **Bangladesh-first** | Bangla interface, local business terms, the way shops really work here. |
| 📴 **Offline-first** | Your data lives on your device first. Sync happens when the internet is available. |
| 💎 **Premium for everyone** | Polished, fast and simple enough for a first-time smartphone user. |
| 🔐 **Security by design** | Encrypted backups and sync, with strict access between linked parties. |
